# \# PROG6221POE - Cybersecurity Awareness Chatbot

# 

# \## Description

# A console-based Cybersecurity Awareness Chatbot built in C# (.NET 8.0) for South African citizens. The chatbot educates users on cybersecurity topics such as phishing, password safety, and safe browsing.

# 

# \## Features

# \- Voice greeting on startup

# \- ASCII art display

# \- Personalised user interaction

# \- Cybersecurity topic responses

# \- Input validation

# \- Coloured console UI with typing effect

# 

# \## How to Run

# 1\. Clone the repository

# 2\. Open PROG6221POE.sln in Visual Studio 2022

# 3\. Build and run the project (Ctrl + F5)

# 

# \## Requirements

# \- Visual Studio 2022

# \- .NET 8.0

# \- System.Windows.Extensions NuGet package
